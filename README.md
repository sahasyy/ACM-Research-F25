This is a simple implementation for converting an AR (Autoregressive model) to a Diffusion based LLM. This only outlines the first step, which is the noising/masking process. The codebase uses GPT, and a Shakespeare dataset for preliminary testing. The resultant text is then run through a noise function and shown in iteratively in the noised_output.txt. 

### File Descriptions

* **main.py**: The main Python script to train and run the character-level GPT model.
* **main.ipynb / gpt\_dev.ipynb**: Jupyter Notebooks containing a detailed, cell-by-cell implementation and explanation of the GPT model.
* **input.txt**: The training dataset, containing the complete works of William Shakespeare.
* **gptoutput.txt**: Sample text generated by the trained GPT model.
* **noise.py**: A script that applies iterative masking (noise) to an input text file (`gptoutput.txt`) to simulate a diffusion process.
* **noised\_output.txt**: The output from `noise.py`, showing the text at various stages of the noising process, from 0% to 100% noise.

### How to Run the Project

#### Prerequisites

* Python 3.x
* PyTorch
* Hugging Face Transformers library (`pip install transformers`)

#### Steps

1.  **Train the Model**: Run the main script to train the GPT model on the provided `input.txt` dataset.
    ```bash
    python main.py
    ```
    This will train the model, print the loss at evaluation intervals, and generate a 2000-character text sample upon completion. You can save this output to `gptoutput.txt`.

2.  **Apply Diffusion Noise**: To simulate the noising process on the generated text, run the `noise.py` script.
    ```bash
    python noise.py
    ```
    This script reads from `gptoutput.txt`, applies noise over 10 steps, and writes the results to `noised_output.txt`.
